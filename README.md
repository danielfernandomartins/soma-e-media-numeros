# 📊 Análise Básica de Números em C++

Programa em C++ para leitura de uma coleção de números e cálculo de estatísticas simples.

## Funcionalidades

- Leitura de N valores
- Identificação de maior e menor número
- Cálculo da média
- Ordenação crescente
- Exibição formatada dos resultados

## Tecnologia

**C++**

## O que demonstra

- Vetores
- Laços
- Algoritmos da biblioteca padrão
- Cálculos numéricos
- Ordenação
- Organização de saída

## Como explicar em entrevista

> "Usei esse exercício para praticar manipulação de coleções em C++. Além de calcular média, maior e menor valor, também trabalhei com ordenação e saída formatada."

## Papel no portfólio

Projeto de fundamentos em estruturas e algoritmos básicos.
